Before a vendor is used in production, review security controls, incident notification, access/audit logs, deletion, backup, data location, subprocessors, model training/secondary use, availability, rate limits, exportability, and exit path. Contractual responsibility must be explicit. Do not describe a vendor as compliant merely because it publishes a security page.
