# Callback protocol

A callback is a specific commitment, not a vague promise. Capture the preferred number, date, time, time zone, reason, and responsible person.

Confirm:

> “I have {date} at {time} in {time zone}, using {number}, and the purpose is {purpose}. Is that correct?”

Check the calendar and closer availability before confirming. If the prospect asks not to be contacted, use the opt-out process instead. A callback request is not automatically consent for unrelated future marketing.
